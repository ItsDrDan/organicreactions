# Organic Reactions Studio (CHEM 3B)

Interactive study game by Dr. Dan (ItsDrDan) for CHEM 3B organic reactions.

- **Identify the Reaction**: name the reaction type or general class
- **Draw the Product**: draw the product from reactant names
- **Draw the Reactant**: work backward from the product
- **Full Reaction**: draw the reactant, identify the type, draw the product

Single self-contained `index.html`; works on GitHub Pages and embedded in Canvas.
Current version: v1 (organic-reactions-v1).
